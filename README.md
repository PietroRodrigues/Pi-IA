# Pi-IA

Assistente de inteligência artificial local desenvolvido em C# e .NET, com integração a modelos de linguagem, reconhecimento de voz e execução de ferramentas locais.

## Sobre o projeto

O Pi-IA é um projeto pessoal voltado à construção de um assistente local capaz de receber comandos, conversar com um modelo de linguagem e executar funcionalidades através de ferramentas integradas à aplicação.

O projeto foi desenvolvido com foco em integração entre componentes, separação de responsabilidades e exploração de recursos de inteligência artificial executados localmente.

## Tecnologias

C#
.NET
Ollama
HTTP
JSON
Whisper.net
NAudio

## Arquitetura

O projeto é organizado em componentes com responsabilidades distintas, incluindo agente, assistente, integração com LLM, ferramentas e recursos de voz.

Entre os principais componentes estão o cliente de comunicação com o Ollama, serviços de agente e um sistema de ferramentas para execução de funcionalidades específicas.

## Integrações

### Ollama

O projeto utiliza o Ollama para comunicação com um modelo de linguagem local através de requisições HTTP e processamento de respostas JSON.

### Reconhecimento de voz

O reconhecimento de voz é implementado utilizando Whisper.net, com suporte a processamento local do modelo Whisper.

### Áudio

A captura e manipulação de áudio utiliza a biblioteca NAudio.

## Principais conceitos explorados

Desenvolvimento de aplicações em C# e .NET, programação assíncrona, comunicação HTTP, serialização e desserialização JSON, integração com modelos de inteligência artificial, processamento de áudio, reconhecimento de voz, organização modular e execução de ferramentas.

## Status

Projeto em desenvolvimento contínuo. A arquitetura e as funcionalidades estão sendo evoluídas conforme novos recursos são implementados.

## Objetivo

Explorar na prática o desenvolvimento de um assistente de IA local e aprofundar conhecimentos em C#, .NET, integração de serviços, inteligência artificial e arquitetura de software.
